# Zoo Management System 🐾

## Project Description

This project is a Zoo Management System that maintains records of animals, staff, caretakers, and zoo inventory. The system helps manage data efficiently using Excel files and Python.

## Files Included

* Animal_Record.xlsx → Animal information
* Animal regular checkup Records.xlsx → Medical checkups
* Caretaker.xlsx → Caretaker details
* Manager.xlsx → Manager records
* StaffRec(WCS).xlsx → Staff information
* zoo_inventory.xlsx → Zoo inventory data
* SourceCode.ipynb → Python code for processing data
* Group16_CSE_100_Zoo MGS.pdf → Project documentation

## Technologies Used

* Python
* Jupyter Notebook
* Excel
* Data Processing
